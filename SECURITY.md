# Security Policy

## Reporting a vulnerability

Please report vulnerabilities privately through GitHub: **Security → Report a vulnerability** on this repository. Do not open a public issue for security problems.

## Keeping your data private

Upleveler stores your work logs, ladder and reports only on your computer, in `~/.upleveler/`. When you report a bug or ask for help:

- Do not paste real work logs, career-ladder documents or reports into issues. Use a small made-up example instead.
- Never share API keys or the values of the environment variables named in `api_key_env`.
